## 16:17 — Clear device attendance after JSON backup

**Why:** Retention should also remove old punches from the ZKTeco, only after a verified JSON backup.

**Files:**
- `app/Services/BiometricLogCollector.php`
- `app/Services/BiometricLogRetentionService.php`
- `app/Services/ZkTecoDeviceReader.php`
- `resources/views/collector/dashboard.blade.php`
- `tests/Feature/BiometricLogCollectorInsertTest.php`
- `docs/user-guide/generate-pulse-collector-user-guide-docx.py`
- `docs/user-guide/Pulse-Biometric-Collector-User-Guide.docx`

**Summary:**
- On collect, if a device still has a punch older than Months to keep, Pulse writes every attendance row on that device to a JSON backup, verifies the file, then clears the device attendance log.
- ZKTeco can only clear the full attendance log. Punches still inside the retention window stay in Pulse. Users and fingerprints are not removed.
- If the JSON backup cannot be written or verified, the device log is left untouched.

## 17:11 — Device clear only at month end

**Why:** Old punches on the time clock should be erased at the end of the month, after a checked JSON backup.

**Files:**
- `app/Services/BiometricLogCollector.php`
- `app/Services/BiometricLogRetentionService.php`
- `app/Models/BiometricDevice.php`
- `database/migrations/2026_10_12_171000_add_attendance_cleared_through_month_to_biometric_devices.php`
- `resources/views/collector/dashboard.blade.php`
- `tests/Feature/BiometricLogCollectorInsertTest.php`
- `docs/user-guide/generate-pulse-collector-user-guide-docx.py`
- `docs/user-guide/Pulse-Biometric-Collector-User-Guide.docx`

**Summary:**
- Time-clock attendance is cleared on the last day of the month, or on the next collect if that day was missed.
- Clear runs only when the device still has a punch older than Months to keep, and only after the JSON backup is checked to include those punches.
- A second collect the same month does not clear the clock again.
