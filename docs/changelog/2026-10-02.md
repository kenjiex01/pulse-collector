## 14:20 — Fix desktop loader stuck (PHP request queue)

**Why:** Pulse hung on “Loading… Please wait” because the single-threaded PHP server queued long auto-collect and updater `check` requests while the full-screen loader counter never reset.

**Files:**
- `resources/views/collector/layout.blade.php`
- `resources/views/collector/partials/desktop-updater-overlay.blade.php`
- `app/Providers/AppServiceProvider.php`
- `app/Providers/NativeAppServiceProvider.php`
- `app/Services/DesktopUpdaterService.php`
- `app/Http/Controllers/DesktopUpdaterController.php`
- `app/Console/Commands/CheckDesktopUpdatesCommand.php`
- `tests/Unit/DesktopUpdaterServiceTest.php`

**Summary:**
- Auto-collect runs again via `BiometricAutoCollectWorker` child process; removed blocking HTTP `collect/auto` polling from every page
- Updater `check` is queued to `desktop:check-updates` so page loads are not blocked for ~55s
- Loader skips background URLs (updater status/check/install); reset overlay on `load` / `pageshow` so aborted navigations do not stick
