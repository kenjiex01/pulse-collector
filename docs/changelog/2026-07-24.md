## 18:20 — Harden SQL restore: converter edge cases + upload limits

**Why:** MySQL restore hit `unrecognized token "8mb4_unicode_ci"` — the type parser split `utf8mb4`; also large dumps were blocked by low PHP upload limits.

**Files:**
- `app/Support/MysqlToSqliteDumpConverter.php`
- `app/Services/DatabaseBackupService.php`
- `app/Http/Controllers/DatabaseController.php`
- `config/uploads.php`
- `resources/views/database/index.blade.php`
- `tests/Unit/MysqlToSqliteDumpConverterTest.php`

**Summary:**
- Converter now strips `CHARACTER SET` / `COLLATE` (space **and** `=` forms) and column noise **before** type parsing, so charset values never leak (`8mb4...`).
- Balanced-paren extraction for `CREATE TABLE` body, `PRIMARY KEY`, `UNIQUE`/`KEY` lists — handles enum lists, `USING BTREE`, and prefix lengths (`` `col`(191) ``).
- Type normalization simplified to affinity (INTEGER/NUMERIC/REAL/BLOB/TEXT); `_utf8mb4'x'` default introducers, `CURRENT_TIMESTAMP()`, and `b'0'` bit literals normalized.
- PDO import splitter rewritten to respect quotes/comments so a `;` or newline inside a value no longer splits statements (also fixes native SQLite dumps).
- Upload limits raised & aligned: `sql_restore_max_kb` = 256 MB; bundled PHP `upload_max_filesize` 256M / `post_max_size` 300M / `memory_limit` 1024M / `max_execution_time` 0.
- Restore form notes MySQL auto-conversion, safety auto-restore, and the max size.

## 18:00 — Support restoring MySQL / phpMyAdmin dumps on SQLite desktop

**Why:** Uploading a mysqldump `.sql` failed with `near "SET": syntax error` — the desktop DB is SQLite, so MySQL-only syntax can't import as-is.

- `app/Services/DatabaseBackupService.php`
- `tests/Unit/MysqlToSqliteDumpConverterTest.php`
- `tests/Unit/DatabaseBackupServiceGzipTest.php`

**Summary:**
- New converter translates MySQL dumps to SQLite: drops `SET`/`LOCK TABLES`/`/*! */` directives, rewrites backticks to `"`, strips `ENGINE=`/charset/collate/comments, folds `AUTO_INCREMENT` PK into `INTEGER PRIMARY KEY AUTOINCREMENT`, maps `enum`/`unsigned`/types, and decodes MySQL backslash string escapes (`\'`, `\n`, etc.).
- `KEY`/`UNIQUE KEY` become table-prefixed `CREATE INDEX` / `UNIQUE(...)`; `FOREIGN KEY` constraints dropped.
- Restore auto-detects MySQL dumps and converts before staging validation + live import; SQLite backups still copied verbatim.
- Fixed pre-existing gzip backup filename regex to allow the `uniqid` suffix.
