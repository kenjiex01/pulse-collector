## 12:45 — Employee Load: auto-detect loading period from date range

**Why:** The loading period already carries its own class date range (`classes_start_date`–`classes_end_date`), so the user should just pick a date range and let Pulse resolve the enrollment period — no manual period dropdown.

**Files:**
- `app/Services/EmployeeLoadTemplateService.php`
- `app/Services/EmployeeLoadUploadService.php`
- `app/Http/Controllers/TimekeepingEmployeeLoadController.php`
- `routes/web.php`
- `resources/views/timekeeping/employee-load/_upload-form.blade.php`
- `resources/js/app.js`

**Summary:**
- Added `EmployeeLoadTemplateService::resolvePeriodForRange()` — matches the selected date range against each period's `classes_start_date`/`classes_end_date` and picks the best-overlapping loading period; throws a clear error when none covers the dates.
- `buildRows()` and `buildTemplateContent()` now take only `date_from`/`date_to`; the period is resolved internally.
- Controller: `downloadTemplate` no longer requires `enrollment_period_id`; `processUpload` resolves the period server-side (quietly) to store `enrollment_period_id`/label on the batch. Removed the `enrollmentPeriods` JSON action.
- Removed the `timekeeping/employee-load/enrollment-periods` route.
- Modal: removed the Enrollment Period dropdown; Date From/To are now the only inputs, and the Download Template link syncs on dates alone.

## 13:15 — Employee Load: fix "Unknown" template download

**Why:** When Skolaris credentials are missing (or the API errors), the `target="_blank"` template link opened the redirected error page in a new tab, which the browser saved as a nameless "Unknown" file.

**Files:**
- `app/Http/Controllers/TimekeepingEmployeeLoadController.php`
- `resources/views/timekeeping/employee-load/_upload-form.blade.php`
- `resources/views/timekeeping/employee-load/index.blade.php`

**Summary:**
- Template download now returns an explicit `Content-Type: text/csv; charset=UTF-8` + `Content-Disposition: attachment; filename="…"` response so the file always has a proper name/extension.
- Removed `target="_blank"` from the Download Template link and added `data-no-loader`, so a failed download surfaces the flash error on the page instead of a stray blank tab.
- Fixed stale modal description (no longer mentions the removed enrollment period dropdown).
